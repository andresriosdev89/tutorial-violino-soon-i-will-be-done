# Tutorial de Violino - Soon I Will Be Done

Tutorial interativo para a parte de Violino 2 de **Soon I Will Be Done**.

## Recursos

- Visualização da corda e do número do dedo em primeira posição.
- Cores diferentes para corda e dedilhado.
- Estudo dividido em dez trechos.
- Reprodução nota por nota e automática.
- Música completa com acompanhamento visual do dedilhado.
- Reprodução didática com timbre sintetizado de violino.
- Layout responsivo para computador, tablet e celular.

## Publicação no Render

O projeto é um site estático sem etapa de compilação. A configuração está no arquivo `render.yaml`.
